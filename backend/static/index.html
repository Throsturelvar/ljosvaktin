About the data

Three open data services, regularly refreshed by the backend. No registration, no passwords.

Aurora activity

NOAA SWPC measures disturbances in Earth's magnetic field and publishes the Kp index together with a forecast for the coming hours.

Cloud cover, temperature and wind

MET Norway provides an hourly forecast for each location. Wind chill is calculated from temperature and wind speed using the standard formula.

Darkness and moon

sunrisesunset.io calculates sunset, darkness and moon position from each location's coordinates.
